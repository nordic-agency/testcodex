# Lektiehjælp.nu

En enkel, statisk hjemmeside skrevet i HTML og CSS, der præsenterer et fiktivt
lektiehjælpskoncept på dansk. Siden beskriver services, arbejdsgang, udtalelser,
nøgletal og en kontaktformular.

## Struktur

- `index.html` – markup med sektioner for hero, services, proces, testimonials,
  nøgletal og kontakt.
- `styles.css` – styling med fokus på moderne, responsivt layout.

Åbn `index.html` i din browser for at se siden.
